### Featured projects

End-to-end work across engineering and analytics — pipelines, warehouses, GenAI tooling, and decision dashboards.

**[Azure Spotify Data Pipeline →](https://github.com/chitranshpatel/azure-spotify-data-engineering-project)**
Enterprise-grade Medallion pipeline (Bronze → Silver → Gold) with ADF orchestration, Auto Loader ingestion, Delta Live Tables, Unity Catalog governance, and CI/CD via Databricks Asset Bundles.
`Azure` `Databricks` `Spark` `Delta Live Tables`

**[Yelp Reviews End-to-End Analysis →](https://github.com/chitranshpatel/yelp-reviews-end-to-end-analysis)**
5 GB JSON ingested through S3 into Snowflake via external stages, enriched with a Snowflake Python UDF for sentiment, then analysed across ten business questions in SQL.
`Snowflake` `Python` `Amazon S3` `SQL`

**[Retail SQL Assistant →](https://github.com/chitranshpatel/retail-sql-assistant)**
Natural-language-to-SQL app for non-technical users. Safe, SELECT-only generation with allow-listed schema guardrails, multi-model LLM routing scored on grounding, cost, and latency.
`Python` `GenAI` `Postgres` `Streamlit`

**[PySpark + dbt Pipeline →](https://github.com/chitranshpatel/PySpark-DBT-End-to-End-Data-Engineering-Project)**
Streaming ingestion through a Medallion lakehouse into a dbt star schema — Spark Structured Streaming, modular PySpark OOP transforms, and dbt snapshots with SCD Type-2.
`PySpark` `dbt` `Databricks` `Spark`

**[NSW Fuel Pricing Intelligence →](https://github.com/chitranshpatel/fuel-pricing-intel)** &nbsp;·&nbsp; [live demo](https://nsw-fuel-pricing.streamlit.app)
Market-cycle and competitor-pricing dashboard on public NSW FuelCheck data, with anomaly detection and a suburb-level heatmap. A local DuckDB warehouse keeps the whole thing file-based.
`Python` `DuckDB` `Streamlit` `Plotly`

**[Retail Shrink Analytics →](https://github.com/chitranshpatel/retail-shrink-analytics)** &nbsp;·&nbsp; [live demo](https://retail-shrink-analytics.streamlit.app)
A decision tool that turns a dense data table into a triaged, drill-down dashboard — entities ranked worst-first by margin decline, with validated dollar logic underneath every percentage.
`Python` `Streamlit` `Plotly`
